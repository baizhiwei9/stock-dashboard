# 缠论主升浪 - 长期计划配置

## 一、计划概述
- **计划名称**: 全市场股票多头排列筛选系统
- **创建时间**: 2026-02-08
- **目标**: 每日自动筛选A股多头排列股票（股价>ma20>ma40>ma80>ma160），按年内涨幅排序取Top20，推送给用户

## 二、核心配置

### 筛选条件
- 股价 > ma20 > ma40 > ma80 > ma160
- 按年内涨幅排序取 Top20
- 范围：全部A股

### 执行时间
- 每个交易日 15:30 自动执行

### 产出要求
- 文件路径：`outputs/股票筛选/YYYY-MM-DD_多头排列Top20.md`
- 内容：股票代码、名称、当前价、ma20/40/80/160、年内涨幅

## 三、数据源配置

### 数据源优先级
1. **恒生聚源数据库**（通过 astock-casestudy 技能）- 当前主要使用
2. baostock - 备用（效率较低）

## 六、日程描述模板（用于创建日程）
```

```

## 七、历史运行经验
1. baostock 效率低，处理全市场需30分钟以上，建议优先用恒生聚源
2. 恒生聚源数据偶有延迟（1-2天），属正常情况
3. 每日筛选约800-1100只股票满足条件

> **报告日期**：2026年10月13日
> **观察窗口**：2026年10月8日(周三)-10月10日(周五)，共3个交易日（国庆长假10/1-10/7，节后首周）

## 核心结论

**ETF托底力度强劲但两融持续失血，北上小幅回流——国庆后首周资金面"一强三弱"格局鲜明。** 股票ETF单周净申购约383亿元（以科创50/半导体/创业板宽基为主），是市场唯一确定性增量来源；但两融连续净卖出104亿元、活跃度回落至2024年9月以来新低，杠杆资金回补幅度明显弱于节后季节性常态；北上资金小幅回流但力度有限（估算净流入0至净流出14亿元区间）；主动偏股基金仓位仅小幅回升。整体看，**ETF仍是阶段主要买入力量，但杠杆资金缺位制约了反弹高度** [(国金证券)](https://pdf.dfcfw.com/pdf/H3_AP202610131830379839_1.pdf) [(国信证券)](https://data.eastmoney.com/report/zw_strategy.jshtml)。

## 一、资金共识矩阵

以申万一级行业为行，五大类资金为列，用 **+/-/0** 标记方向。数据来源为各资金维度的行业拆分结论（ETF来自国金证券行业分拆、两融/北上/龙虎榜来自行业净买卖方向、主动偏股基金来自二次规划法仓位变动）。**3路以上同向标记为"高共识"**。

| 行业 | ETF | 北上 | 两融 | 龙虎榜 | 主动基金 | 共识度 | 综合方向 |
|------|-----|------|------|--------|---------|--------|---------|
| **电子** | +++ | + | --- | + | ++ | ★★★★ | **强流入** |
| **通信** | +++ | + | --- | + | ++ | ★★★★ | **强流入** |
| **医药** | ++ | - | + | + | 0 | ★★ | 弱流入 |
| **电力设备/新能源** | ++ | - | --- | 0 | --- | ★☆ | 分歧 |
| **军工** | + | 0 | 0 | 0 | ++ | ★★ | 弱流入 |
| **有色金属** | 0 | 0 | --- | - | --- | ★★★ | **流出** |
| **基础化工** | 0 | - | - | + | --- | ★★ | 弱流出 |
| **机械** | 0 | - | --- | - | 0 | ★★★ | **流出** |
| **非银金融** | 0 | - | 0 | 0 | 0 | ★★ | 弱流出 |

> **注**：+/-/0 基于各来源行业拆分结论的综合判断。ETF行业方向来自国金证券"股票ETF主要净买入TMT、医药、电新等板块"。北上行业方向来自国金证券综合判断。两融来自"主要净买入医药、汽车、农林牧渔，净卖出电子、通信、机械"。主动偏股基金来自"加仓电子、通信、军工，减仓有色、化工、电新"。**★★★★为最高共识度（4-5路同向），★★★为3路同向（高共识），★★为2路（中等），★为1路或分歧**。

**关键发现**：
- **TMT（电子+通信）是五类资金中最强共识流入方向**——ETF大幅净申购科创50/半导体相关标的，北上活跃股中电子通信买卖总额占比上升，主动偏股基金加仓，仅两融逆势净流出。
- **有色金属、机械是共识流出方向**——两融大幅净卖出，主动偏股基金减仓，北上也可能净卖出。
- **电力设备/新能源方向分歧最大**——ETF净申购（创业板指相关），但两融净卖出（-37.94亿元居首），主动偏股基金减仓。

### 3.1 股票ETF资金流向：宽基ETF放量净申购，科技/医药/电新为主要流向

|------|--------|-------------------|------|

**季节性分析**：

国庆后首周两融通常有回补效应。以史为鉴，2019-2025年国庆后首周两融余额变化中，多数年份呈现小幅回补（融资净买入转正）。但**本周年两融净卖出103.88亿元，回补力度明显弱于季节性常态**，反映出杠杆资金对节后市场信心不足。国金证券明确指出"以两融为代表的杠杆资金的回补幅度暂时弱于季节性，后续依然需要关注两融资金能否逐步回流"。

> **解读**：两融数据的核心信号是"全面流出+历史低位"。融资余额从6月高点3万亿降至2.53万亿，科技股是重灾区（电子净卖出284亿元）。两融成交占比8.19%处于历史低位，说明杠杆资金参与度持续萎缩。这与国金策略周报的判断一致——"两融活跃度继续回落至2024年9月下旬以来的新低"。

## 五、测算误差与风险说明

| 数据维度 | 估算方法 | 主要误差来源 | 局限性 |
|---------|---------|------------|--------|
| **ETF净申购** | 份额变动×成交均价 | 跨市场ETF申赎延迟确认、新基金建仓期数据噪声 | 行业拆分基于指数成分权重，与实际ETF管理人操作可能有偏差 |
| **两融数据** | 交易所官方披露 | 10月10日深交所数据暂缺（AKShare接口延迟），全周仅含10/8-10/9共2-3个交易日 | 行业融资净买入为全市场口径，无法区分机构/个人 |
| **北上资金** | 代理变量（中小盘持股变动+活跃股行业比） | 2024年6月起不再披露实时净买卖额，所有数据均为间接估算。**两家机构（国金vs国信）对方向判断存在分歧** | 无法获得精确的行业净流入/流出金额 |
| **主动偏股基金** | 二次规划法（基于持仓+涨跌幅拆解） | 2026Q3季报尚未披露，使用最近一期数据近似。模型假设基金不调仓时的持仓变动仅由涨跌幅驱动 | 无法捕捉ETFFOF、QDII等特殊产品 |
| **龙虎榜** | 交易所公开披露 | 仅覆盖异动个股（涨停/跌停/换手率异常），不代表全市场资金流向 | 存在营业部席位对倒、高频交易等噪声 |
| **季节性分析** | 2010年至今国庆后首周统计 | 2014年之前两融余额规模远小于当前，可能影响分位数代表性 | 2024年6月后北向数据口径变化，无法做历史同期对比 |

> **⚠️ 关键风险标注**：
> 1. 北向资金数据因2024年披露规则变化，精确行业流向**暂不可得**，本报告使用代理变量估算，置信度为MEDIUM。
> 2. 主动偏股基金仓位变动基于模型估算，精确数据需待2026Q3季报披露（预计10月下旬）后验证。
> 3. 深交所10月10日两融数据暂缺，全周数据可能略有低估。
> 4. 本报告观察周仅含2-3个交易日（国庆后10/8-10/10），样本量偏少，周度数据的波动性可能高于常态。

## 六、总结与展望

### 本周资金面核心特征

1. **ETF一枝独秀**：383亿元净申购，科技宽基（科创50/半导体/创业板）是绝对主力，个人投资者是主要买入力量。ETF自9月28日以来累计净流入超700亿元，正在形成阶段性底部买入信号。

2. **两融弱于季节性**：净卖出104亿元，活跃度创15个月新低。电子行业融资净卖出284亿元居首，杠杆资金对科技股信心明显不足。与历年国庆后两融通常回补的常态形成反差。

3. **北上小幅回流**：活跃度从14.3%回升至15.3%，边际增量偏向电子/通信。但总净流入额接近零轴（国金估算小幅净买入 vs 国信估算净流出14亿），力度有限。

4. **主动基金小幅加仓**：仓位回升，加仓TMT/军工，减仓有色/化工。但整体幅度不大，且存在"反弹减仓、下跌加仓"的逆势操作特征。

5. **龙虎榜热度回升**：买卖总额环比上升，农林牧渔/传媒/家电/化工板块游资活跃度提升。

### 资金共识与分歧

- **最强共识（买入）**：电子/通信 → ETF+北上+主动基金三路同向买入，仅两融逆势流出
- **最强共识（卖出）**：有色金属/机械 → 两融+主动基金+北上三路同向流出
- **最大分歧**：电力设备/新能源 → ETF买入 vs 两融/主动基金卖出

### 后续关注点

1. 两融资金能否止跌回升——当前担保比例已接近前期低点，若继续回落可能触发被动平仓
2. 2026Q3基金季报披露（10月下旬）后的仓位验证
3. 北向资金披露规则是否进一步细化
4. 美联储10月议息会议对全球流动性的影响
5. 中美贸易摩擦修复进展对科技股资金流向的影响

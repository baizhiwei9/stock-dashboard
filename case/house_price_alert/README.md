# 京沪房价指数技术预警（house_price_alert）

只管 **北京、上海** 两城的房价指数（月度），跑一遍 KDJ/MACD，命中的信号**汇总成一封带图
邮件**发出去。70 城数据仍在库里（取数不设限），但预警不扫全城——70 城一起报就是噪音。

## 数据与指标

| | 内容 |
|---|---|
| 源 | 东方财富 `RPT_ECONOMY_HOUSE_PRICE`（`data_hub.house.sources.price70` 直连） |
| 覆盖 | 库里 **70 城 × 190 个月**（2011-01 ~ 最新月），本任务只取京沪 |
| 价格序列 | **二手住宅环比连乘**还原的合成价格（该城首月 = 100），**不是元/㎡** |
| 指标 | KDJ(9,3,3)、MACD(12,26,9)、20 月均线（中轨） |

## 触发规则

| 规则 | 含义 | 方向 |
|---|---|---|
| MACD 零轴上穿 / 下破 | 中枢转多 / 转空 | bull / bear |
| KDJ 中轴(50)上穿 / 下破 | 中枢转多 / 转空 | bull / bear |
| 价格上穿 / 下破 MA20 | 中轨突破 | bull / bear |
| KDJ 超买（K>=80 或 J>=100） | 注意回调 | warn |
| KDJ 超卖（K<=20 或 J<=0） | 注意反弹 | watch |
| **处于超买区 / 超卖区** | 状态提醒 | warn / watch |

两点口径要说明：

1. **「处于区间」也算一条信号**，按 `城市|类型|月份|区间` 去重 → **每月最多提醒一次**。
   这样"京沪已经在超买区"不会被漏掉，也不会天天刷。
2. **超买超卖的「进入」按事件判**（本期进、上期不在）：月度指数单边下行时 KDJ 会长期钝化
   贴 0，若按「停留」判，全城会同时冒出几十条超卖，等于没预警。

## 邮件里有什么

1. **当前状态表**（永远有）：城市 / 月份 / 合成价格 / K / D / J / DIF / DEA / 区间
2. **本轮新增信号**（去重后）：方向 + 触发原因
3. **附件图**：两城一张 PNG，每城三栏 = 价格+MA20 / KDJ(80-20 带) / MACD(零轴)

没有新增信号时**不发空邮件**（`--force` 可强制全量重报，排查用）。

## 用法

```bash
export PYTHONPATH=/path/to/datahub-multi-tier
python3 run.py                 # dry-run：抓数 → 分析 → 出图 → 打印邮件预览，不发送
python3 run.py --send          # 真发（需先配好 SMTP 环境变量）
python3 run.py --no-fetch      # 不抓新数据，用库里现有的
python3 run.py --kind new      # 换成新建商品住宅指数
python3 run.py --cities 北京,上海,广州   # 临时扩城市（默认就这两个）
python3 run.py --force         # 忽略去重，把当前所有信号当新的
```

邮件环境变量（**凭据只从环境读，不写进仓库**）：

```
SMTP_HOST  SMTP_PORT(默认465)  EMAIL_FROM  EMAIL_TO(逗号分隔)
SMTP_USER  SMTP_PASSWORD  SMTP_SSL(默认开)  SMTP_TLS(默认关)
```

## 产物

- `out/signals.json`：两城分析 + 本轮新增
- `out/signals.md`：人读摘要（就是邮件正文）
- `out/price_tech.png`：技术分析图
- `out/state.json`：去重状态（保留近 12 个月）

## 已知限制

1. **是指数不是单价**：上游只给同比/环比/定基，没有成交金额 → 算不出元/㎡。`合成价格` 只能看
   方向与幅度，不能当房价引用。北京 2026-10 是 189.86、上海 177.95（相对各自 2011 年首月）。
2. **定基字段为空**：东财该报表 `*_BASE` 返回 null。
3. **月度、滞后约 1 个月**：最新一期通常晚一个月，这是源的节律。
4. **KDJ 钝化**：单边行情里 K 会长期贴 0 或 100，此时"进入"信号偏少属正常。
5. **穿越是事件**：只检查最新一期，历史穿越不补报。

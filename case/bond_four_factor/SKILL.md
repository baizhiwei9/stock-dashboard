# 国债期货四因子预测框架

基于**政策信号、资金信号、情绪信号、股债信号**四因子的国债期货方向预测。所有数据来自免费公开渠道，每周更新评分。

## 核心公式

```
国债期货方向 = f(政策30%, 资金30%, 情绪20%, 股债20%)

总分 > 60：看多（收益率下行，期货上涨）→ 多头仓位70-80%
总分 50-60：震荡偏多 → 多头仓位40-50%
总分 40-50：震荡观望 → 轻仓或空仓
总分 < 40：看空（收益率上行，期货下跌）→ 空仓或反手做空
```

## 四因子评分规则

### 一、政策信号（30%）

| 指标 | 数据源 | 评分标准 |
|------|--------|----------|
| OMO净投放 | 央行官网 pbc.gov.cn | 净投放>1000亿=70, 净回笼>1000亿=30, 区间线性 |
| 央行措辞 | 央行沟通交流页面 | 鸽派(降准降息/宽松/支持)=70, 鹰派(防范风险/稳汇率)=30 |
| MLF量价 | 央行官网(每月15日) | 缩量=30, 增量=70, 降息=80, 不变=50 |
| 国债买卖 | 央行官网(月末) | 净买入>500亿=70, 200-500亿=60, <200亿=50, 净卖出=30 |

**关键措辞对照**：
- 鸽派利好：「适时降准降息」「流动性合理充裕」「支持实体经济」「降低融资成本」
- 鹰派利空：「降准降息再等等」「防止资金空转」「防范金融风险」「关注汇率稳定」

### 二、资金信号（30%）

| 指标 | 数据源 | 评分标准 |
|------|--------|----------|
| DR007 vs 逆回购利率 | 中国货币网 | DR007<1.40%=70, >1.50%=30, 区间线性 |
| 1M Shibor | shibor.org | <1.40%=70, 1.40-1.50%=60, 1.50-1.60%=50, >1.60%=40 |
| 1Y AAA同业存单 | 中国货币网 | <1.60%=70, 1.60-1.70%=60, 1.70-1.80%=50, >1.80%=40 |
| 质押式回购成交量 | 中国货币网 | >5万亿=70, 3-5万亿=50, <3万亿=30 |

### 三、情绪信号（20%）

| 指标 | 数据源 | 评分标准 |
|------|--------|----------|
| TL持仓量变化 | 中金所 cffex.com.cn | 增仓+上涨=70, 减仓+上涨=50, 增仓+下跌=30, 减仓+下跌=25 |
| 10Y-30Y利差 | 中债登 | >50bp=70, 30-50bp=50, <30bp=30 |
| IRS利率(FR007) | 中国货币网 | IRS下行=70, 上行=30, 变化<2bp=50 |
| 成交/持仓比 | 中金所 | >1.5=情绪亢奋40, 0.5-1.5=50, <0.5=60(低迷可能见底) |

### 四、股债信号（20%）

| 指标 | 数据源 | 评分标准 |
|------|--------|----------|
| 上证5日涨跌幅 | akshare | >5%=20, 2-5%=35, -2~2%=50, <-5%=80 |
| 创业板/科创50 | akshare | 同上但权重更高 |
| 北向资金净流入 | akshare | >100亿=20, -100~100亿=50, <-100亿=80 |
| 债基申赎(周度) | 基金业协会 | 份额增加=60, 减少>100亿=30, 变化不大=50 |

## 执行流程

1. 运行 `python3 main.py` 全自动执行：
   - **央行官网爬虫(pbc.gov.cn)**：OMO净投放、MLF操作、国债买卖（GBK编码静态HTML抓取）
   - **akshare**：Shibor利率、国债收益率、TL期货持仓排名、股指涨跌幅
   - 按四因子规则自动计算评分和方向判断
   - 调用 DeepSeek V4 Flash 做综合研判（成本~$0.0001/次）
2. 输出：Markdown报告 + JSON数据快照（含LLM研判）
3. 数据覆盖率约83%（10/12项），缺失项标注为缺失

## 已知数据限制

- **回购成交量**：CFETS需JS渲染，Eastmoney被封锁，暂无可用源
- **北向资金**：官方2024年8月起停止实时公布，akshare返回NaN

| 情绪 | 20% | XX | XX |
| 股债 | 20% | XX | XX |
| **总分** | | **XX** | |

- 本周vs上周：各因子评分变动及原因

## 局限性

- 政策信号主观性较强，央行措辞需人工判断
- 适合中期配置方向判断，不适合日内交易
- 权重30/30/20/20为经验设定，未经机器学习优化

## 二、算法说明

### DFA-1 去趋势波动分析
对**对数收益率序列**（平稳序列）做 DFA-1：
1. 去均值 + 累积求和（轮廓）
2. 对每个尺度 n，分段做 1 阶线性拟合
3. 计算去趋势波动 F(n) = sqrt(mean((Y-趋势)^2))
4. log(n) ~ log(F(n)) 线性回归，斜率 = Hurst 指数 H

### 算法验证
- 白噪声 → H ≈ 0.53（接近 0.5，正确）
- 布朗运动 → H ≈ 1.50（接近 1.5，正确）

### 尺度参数
| 类型 | 窗口 | 尺度列表 |
|------|------|---------|
| 短周期 | 60日 | [4, 6, 8, 10, 15, 20, 30] |
| 长周期 | 250日 | [10, 15, 20, 30, 40, 60, 80, 100, 150] |
| 波动率 H | 250日 | [10, 15, 20, 30, 40, 60, 80, 100, 150] |

## 四、信号体系

### 优先级：临界 > 金叉/死叉 > 有序/退相

| 信号 | emoji | 条件 | 操作建议 |
|------|-------|------|---------|
| 临界预警 | 🟠 | 短H>0.7 且 波动H>0.7 | 停止开新仓，减仓或买Put |
| 金叉 | 🟢 | 短H上穿长H + 短H>0.55 + 长H>0.5 | 顺势开仓，仓位可积极 |
| 死叉 | 🔴 | 短H下穿长H + 短H<0.55 + ≥2条附加条件 | 清仓或对冲 |
| 有序 | 🟡 | 短H>0.55 且 长H>0.5（非金叉） | 顺势持有 |
| 退相 | ⚪ | 短H<0.5 或 长H<0.5 | 观望为主 |

### 死叉附加条件（满足≥2条）
1. 价格低于 60 日均线
2. 波动率 Hurst > 0.7
3. 短 H < 0.4
4. 近 5 日价格重心下移（5日均线向下）

### 风控标注 ⚠️
- 窗口内单日涨跌幅 > 9%
- 连续 5 日以上零波动（疑似停牌）

## 五、独立日报脚本使用

```bash
# 午盘版（默认）
python hurst_daily.py --skip-push

# 指定日期
python hurst_daily.py 20260817 --skip-push

# 收盘版（自定义标题）
python hurst_daily.py 20260817 --title-suffix 收盘 --skip-push

# 强制重跑（忽略幂等缓存）
python hurst_daily.py 20260817 --force --skip-push
```

### 幂等控制
- 状态库：`土狗分析/hurst_state.db`
- 同一天重复运行自动跳过（`--force` 可强制重跑）

### 交互式卡片特性
独立 Hurst 日报使用飞书 `<details>`/`<summary>` 标签实现交互式折叠：
- **默认展示**：5个指数的概览表格（短H/长H/短长差/波动H/信号/操作建议）
- **每个指数可展开详情**（点击 summary 展开）：
  - 基本指标：今日/昨日短H、今日/昨日长H、短长差、波动率H
  - 价格与均线：当前价、60日均线（含偏离方向和幅度）、5日均线方向
  - 风控警告：涨跌停断层、连续停牌等
  - 信号判定依据：金叉/死叉/临界三条判定线逐条展示 ✅/❌ 满足情况
- **底部整体状态区**：信号分布统计 + 综合判断
